## 1. 법규별 검증 대상 및 라이브러리

| 법규 | 시험 상황 | 기대 화면/음향 | 검증 라이브러리 |
|------|-----------|----------------|-----------------|
| **R158 (PDW)** | 후진(R단) 변속 + 후방 장애물 감지 | 후방 경고 팝업·R단 표시 / 경고음(beep) | 영상: OpenCV·OCR / 음향: librosa |
| **R175 (PMSA)** | IG ON 시 고장 존재 / 페달 오조작 | PMSA 고장표시 팝업 등장·해제 | 영상: OpenCV·OCR |
| **Euro NCAP (AEB)** | 긴급제동 발생 | 충돌경고·긴급제동 팝업 / 경고 사운드 | 영상: OpenCV·OCR / 음향: librosa |

- 영상: 화면 일치 = **OpenCV**(템플릿/특징점 매칭), 문구 판독 = **Tesseract OCR**
- 음향: 경고음 시작 시점 = **librosa**(onset) + 주파수 대역 필터

---

## 2. 테스트 내용 (요약)

1. **정확도** — 정답 내장 합성 샘플로 검출 시각 오차(ms)·성공률·오탐(FP/FN) 측정
2. **강건성** — 노이즈/조명/해상도/차종 변화를 주입해 검출률 변화 측정 (라이브러리 선정 근거)
3. **경계** — 프레임레이트(30/60fps) 분해능이 ±30ms 동기 기준에 미치는 영향

---

## 3. 가장 범용적인 라이브러리 조합

```
영상 = OpenCV + Tesseract(OCR)
음향 = librosa + scipy.signal
공통 = NumPy
```
> 핵심 2개: 영상 **OpenCV**, 음향 **librosa** (사실상 업계 표준)

---

## 4. 검토 라이브러리 (용도별)

| 구분 | 라이브러리 | 용도 |
|------|-----------|------|
| 영상-매칭 | OpenCV | 템플릿 매칭(NCC), 특징점 매칭(SIFT/ORB) |
| 영상-유사도 | scikit-image | SSIM (조명 변화 강건) |
| 영상-해시 | ImageHash | pHash, 초고속 화면 동일성 비교 |
| 영상-OCR | Tesseract / PaddleOCR | 경고 문구 판독(차종 일반화) |
| 음향-분석 | librosa | onset 검출, STFT, 특징 추출 |
| 음향-신호처리 | scipy.signal | 밴드패스 필터, 정합필터(상호상관) |
| 음향-IO | soundfile / sounddevice | WAV 입출력, 실시간 캡처 |
| 공통 | NumPy | 수치 연산 |
| (보조) LLM/VLM | Claude 등 | 오프라인 — 템플릿 라벨링, 모호 케이스 검수, 리포트 생성 |

> 선정 메모: 상업용은 **SURF(특허) 회피 → SIFT/ORB**. 고정 UI는 템플릿+pHash, 차종 다양성은 OCR 우선.
