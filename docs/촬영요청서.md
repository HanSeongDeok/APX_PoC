# 참고 영상 촬영 요청

## 요청 사항
아래 화면을 담은 영상을 **2부** 부탁드립니다.

- **1부**: 삼각대나 거치대로 **흔들림 없이** 촬영
- **2부**: 손으로 들고 **가볍게 움직이며** 촬영

각 영상에 아래 화면이 모두 들어가면 됩니다.

1. 클러스터 정면 화면
2. 클러스터 경고 팝업 화면
3. 기어 P 화면
4. 기어 R 화면
5. 기어 N 화면
6. 기어 D 화면

## 촬영 시 참고
- 각 화면을 **5초 정도 멈춰서** 담아 주세요.
- 화면에 **빛 반사가 적을수록** 좋습니다. (조명 반사가 화면에 직접 비치지 않게)
- 화면 밝기는 평소 사용하시는 그대로면 됩니다.

편집이나 파일 정리는 저희가 하니, **찍어서 원본만 전달**해 주시면 됩니다.
